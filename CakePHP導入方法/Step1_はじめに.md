## 1. はじめに

### 1-1. マニュアルの目的

本マニュアルは、Windows PCにCakePHPの開発環境を構築するための手順を説明するものである。

CakePHPは、PHPを使用してWebアプリケーションを効率的に開発するためのフレームワークである。

フレームワークとは、アプリケーションの開発に必要な基本的な仕組みをあらかじめ用意したものである。

CakePHPを使用するためには、PHPやWebサーバー、データベースなどの開発環境を準備する必要がある。

本マニュアルでは、必要なソフトウェアのインストールから初期設定、動作確認までを順番に解説する。

**最終目標：CakePHPを使用してWebアプリケーションの開発を開始できる状態にする。**

### 1-2. 対象環境

本マニュアルでは、以下の環境を想定する。

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / Windows 11 |
| インターネット接続 | 必要 |
| 管理者権限 | ソフトウェアのインストールが可能であること |
| 開発環境 | 必要なソフトウェアがインストールされていない状態 |
| 対象者 | CakePHPや開発環境の構築を初めて行う生徒 |

既に一部のソフトウェアがインストールされている場合は、バージョンや設定を確認したうえで必要な手順を実施する。

**注意：** 学校や企業の管理するPCでは、ソフトウェアのインストールが制限されている場合がある。その場合は管理者に確認する。

### 1-3. 使用するソフトウェア

CakePHPの開発環境を構築するため、以下のソフトウェアを使用する。

| ソフトウェア | 役割 |
|---|---|
| XAMPP | Webサーバーやデータベースなどの開発環境を構築する |
| PHP | Webアプリケーションの処理を実行するプログラミング言語 |
| Composer | PHPのライブラリや依存関係を管理する |
| CakePHP | PHPを使用してWebアプリケーションを開発するフレームワーク |
| Visual Studio Code | プログラムの作成・編集を行うコードエディター |

#### XAMPP

XAMPPは、Webアプリケーションの開発に必要なソフトウェアをまとめて導入できるツールである。

主に以下の機能を使用する。

| 機能 | 役割 |
|---|---|
| Apache | Webページをブラウザに配信するWebサーバー |
| MariaDB | データを保存・管理するデータベース |
| PHP | Webアプリケーションの処理を実行する |
| phpMyAdmin | ブラウザからデータベースを管理するツール |

PHPはXAMPPに含まれているため、基本的に別途インストールする必要はない。

公式サイト：https://www.apachefriends.org/jp/index.html

#### PHP

PHPは、Webアプリケーションの処理を記述するためのプログラミング言語である。

ログイン処理やデータベースとの連携などに使用する。

CakePHPはPHPで動作するため、PHPを実行できる環境が必要となる。

公式サイト：https://www.php.net/

#### Composer

Composerは、PHPのライブラリや依存関係を管理するツールである。

ライブラリとは、特定の機能をまとめた再利用可能なプログラムのことである。

Composerを使用すると、CakePHPの導入に必要なプログラムをまとめて取得できる。

公式サイト：https://getcomposer.org/

#### CakePHP

CakePHPは、PHPでWebアプリケーションを効率的に開発するためのフレームワークである。

CakePHPでは、MVCという設計方法を採用している。

| 要素 | 役割 |
|---|---|
| Model | データの取得や管理 |
| View | 画面の表示 |
| Controller | リクエストを受け取り処理を制御 |

公式サイト：https://cakephp.org/

#### Visual Studio Code

Visual Studio Code（VS Code）は、プログラムの作成や編集に使用するコードエディターである。

PHP、HTML、CSS、JavaScriptなどのファイルを編集できる。

拡張機能を導入することで、プログラムの入力補助やエラーの確認なども行える。

公式サイト：https://code.visualstudio.com/

### 1-4. バージョンの確認

ソフトウェアには、それぞれバージョンが存在する。

バージョンによって使用できる機能や対応環境が異なるため、インストール前に互換性を確認する必要がある。

特にCakePHPとPHPには対応バージョンの条件があるため、公式ドキュメントで確認する。

#### 使用するバージョン（暫定）

| ソフトウェア | 使用バージョン |
|---|---|
| XAMPP | 8.2.12 |
| PHP | 8.2.12（XAMPP同梱） |
| Composer | 2.x系 |
| CakePHP | 5.4.3 |
| Visual Studio Code | インストール時の安定版 |

CakePHP本体は5.4.3を使用する。その他のソフトウェアは暫定バージョンであり、開発チームで正式に決定した段階で修正する。

CakePHP 5.4.3にはPHP 8.2以上が必要である。本マニュアルではXAMPP同梱のPHP 8.2.12を使用する。

参考：[CakePHP 5.4.3の依存条件（公式）](https://github.com/cakephp/cakephp/blob/5.4.3/composer.json)

#### 確認事項

1. CakePHPが対応するPHPのバージョンを確認する。
2. XAMPPに含まれるPHPのバージョンを確認する。
3. 各ソフトウェアの互換性を確認する。
4. 開発チーム内で使用するバージョンを統一する。

公式ドキュメント：https://book.cakephp.org/

**注意：** バージョンが異なると、同じプログラムでも正常に動作しない場合がある。チーム開発では、可能な限り開発環境を統一する。
